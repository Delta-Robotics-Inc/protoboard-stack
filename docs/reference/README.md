# Reference

The Protoboard Stack v0.1 reference set. New here: start with the
[quickstart](../quickstart.md). What is in this release and what is not yet:
[release notes](../releases/stack-v0.1.md).

| Reference | What it covers | Kept accurate by |
| --- | --- | --- |
| [CLI](cli.md) | Every `protoboard` command and option | Generated from `protoboard --help` (`node scripts/reference-docs.mjs`); `packages/cli/test/reference-docs.test.ts` fails when it is out of date |
| [Configuration](configuration.md) | Project layout, `protoboard.config.ts`, `release`, `libraries`, module capability configs, environment variables, which files to commit | Written against `packages/core/src/types.ts`; the reference test checks every command it names |
| [Extensions and skills](extensions.md) | The 12 first-party extensions: capabilities, operations, checks, tools and runtimes, skills, eval cases | Generated from the `protoboard-extension.json` manifests, as the CLI reference |
| [Diagnostic codes](../../packages/ext-hardware/skills/system-compose/references/diagnostic-codes.md) | Every code `protoboard check` reports, what it means and what to do; pointers to the `FW_*` and `REL_*` tables | `packages/cli/test/skills-sop.test.ts` fails on a code the stack emits that it does not list |
| [display.json](display.md) | `.protoboard/display.json`: the diagram's layout, and the 3D view's root, placements (row-major 4×4, millimetres), labels, appearance and camera | Written against the viewer's `DisplayConfig` and UHD's `assemble`; every project's AGENTS.md carries the short form |
| [Render service](render-service.md) | `protoboard views capture`, `views doctor`, `views service`: one warm headless browser per project, captures with overlays and manifests, the transfer limits (`transfer-limits.json`), and the snapshot a visible viewer opens from | Written against `packages/core/src/render-service/`; `packages/core/test/render-service.test.ts` keeps the limits file equal to the built-in copy |
| [Agent view tools (MCP)](view-tools.md) | `view_observe`, `view_select`, `view_highlight`, `view_isolate`, `view_camera`, `view_callout`, `view_mark`, `view_arrow`, `view_explode`, `view_capture`, `view_undo`, `view_claim`, `view_release`, `view_pick`, `view_place_on_face`, `view_orient_by_face`, `geometry_measure`: the route (live tab or headless), refusals, leases, undo per actor, turn-taking, the op log on disk | Written against `packages/cli/src/mcp/view-tools.ts`, `scene.ts` and uhd-viewer `src/cad/state/`; `packages/cli/test/view-tools.test.ts`, uhd-viewer `test/collab.test.ts` |
| [Settings](settings.md) | The user's Protoboard settings (`<home>/settings.json`): open models in place, zoom to the pointer, model info, the long hover delay, the STEP viewer, the export and import folders; `protoboard settings`, the MCP tools `settings_get` and `settings_set`, the Settings page, the change log | Written against `packages/core/src/settings.ts`, `packages/cli/src/settings.ts`, `packages/cli/src/mcp/settings-tools.ts`, `packages/vscode-protoboard/src/userSettings.ts`; `packages/core/test/settings-r2e.test.ts`, `packages/cli/test/settings-r2e.test.ts` |
| [3D view state and live-tab bridge](viewer-bridge.md) | The view-state schema (`uhd-viewer.view-state/v1`), the op log and its version preconditions, `.protoboard/local/viewer-state.json`, and the loopback channel from `protoboard dev` to the open viewer tab | Written against uhd-viewer `src/cad/state/` and `packages/cli/src/dev/bridge.ts`; `packages/cli/test/dev-bridge.test.ts` |
| [Mates, joint limits and interference](mates.md) | The `protoboard.mate` trait and the `<model>.mates.json` sidecar (sha256-bound, mm and Z up), joint limits as hard stops in the sequence, `protoboard mates list\|suggest\|validate`, `protoboard interference` at the sequence's keyframes, the `protoboard/mates` check | Written against `packages/core/src/mates/` and `src/sequence/`; `packages/core/test/mates.test.ts`, `sequence-limits.test.ts`, `mates-check.test.ts`, `packages/cli/test/mates.test.ts`, `interference.test.ts` |
| [Drawings to CAD](drawings.md) | `protoboard drawing inspect\|views\|crop\|dimensions\|compare`: vector PDF and DXF reading, `measured-from-drawing` provenance, re-projection compare, PDF permission flags (refused unless `--ignore-pdf-permissions`), licences | Written against `packages/ext-parts/scripts/drawing/` and `packages/cli/src/drawing.ts`; `scripts/drawing/tests/test_drawing.py`, `packages/ext-parts/test/drawing.test.ts` |
| [Reference tools](reference-tools.md) | The `protoboard.reference-tool/v0` registry, `parts export`, `parts import-step`, `parts attach`, the evidence layout and `measured-from-reference-tool` provenance | Written against `packages/core/src/reference-tool/` and `packages/cli/src/parts-*.ts`; `packages/core/test/reference-tool.test.ts`, `packages/cli/test/parts-export.test.ts`, `parts-import-step.test.ts`, `parts-attach.test.ts` |
| [G-code viewer](gcode-viewer.md) | The viewer's G-code tab (`?gcode=<url>`): the dialects read, one instanced draw, the layer window, caps and decimation | Written against uhd-viewer `src/gcode/` and `src/cad/GcodeView.tsx`; uhd-viewer `test/gcode.test.ts` |
| [Part package (`.uhdpkg`)](uhdpkg.md) | `protoboard package write\|read\|verify`: the zip layout around the part-revision envelope, caps, path and name checks, reproducible bytes | Written against `packages/core/src/uhdpkg/` and `packages/cli/src/package.ts`; `packages/core/test/uhdpkg.test.ts`, `packages/cli/test/package.test.ts` |
| [Update and vulnerability check](update-check.md) | `protoboard inventory`, `protoboard update check\|status\|on\|off`: the once-a-day check against registry.npmjs.org and api.osv.dev, the lookalike deny list, the VS Code toast, how to turn it off | Written against `packages/core/src/update/` and `packages/core/reference/lookalikes.json`; `packages/core/test/update-*.test.ts`, `runtime-install-guard.test.ts`, `packages/cli/test/inventory.test.ts`, `update-check.test.ts` |
| [Issue and feature reporting](issue-reporting.md) | The MCP tools `report_issue`, `request_feature`, `report_send`, `report_list`: the redacted bundle, the confirm step, the request shape for the cloud side (not deployed: nothing is sent while `PROTOBOARD_REPORTS_URL` is unset) | Written against `packages/cli/src/mcp/report-tools.ts`; `packages/cli/test/report-tools.test.ts` |
| [Supported systems](supported-systems.md) | What the CLI, extension, viewer and runtimes run on, each row verified (machine, how, when) or unverified, and the release checklist | Kept by hand at each release (its checklist) |
| [Manufacturing Package](manufacturing-package.md) | `release/<version>/`: layout, `manifest.json` (`protoboard.release/v0`), reproducibility | `scripts/compare-release.mjs` against the committed release records |
| [Library protocol](library-protocol.md) | Pointer to UHD's `uhd-library/v1`, and how the CLI uses it | UHD's own protocol tests |
| [Local telemetry](telemetry.md) | The viewer's crash and performance records in `.protoboard/local/telemetry/` (recorded on your machine only, never sent): fields, retention, how to turn them off, `protoboard telemetry`, and the consent-to-send bundle and request shape | Written against `packages/core/src/telemetry.ts`; `packages/core/test/telemetry.test.ts` covers the writer, the redaction and the switches |
