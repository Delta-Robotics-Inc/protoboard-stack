# parts/local: purchased parts researched in this project

A part the catalog does not have yet is researched here: `<id>.uhd.ts` (a
ModuleDef with cited facts and `assumption` traits), its evidence in
`../evidence/<id>/` (`sources.json`, `verification.json`) and, when it has a
body, a `cad.config.ts` in `<id>/`. The **uhd-part-research**,
**uhd-part-author** and **uhd-part-verify** skills (@protoboardai/ext-parts) are
the procedure; `protoboard parts publish parts/local/<id>.uhd.ts` promotes a
verified part to the catalog.
