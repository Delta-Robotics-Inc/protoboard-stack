# @protoboardai/core

The Protoboard framework: loads projects, resolves parts, runs checks and builds.

Part of [Protoboard](https://github.com/Delta-Robotics-Inc/protoboard-stack), which designs hardware with your AI agent. The `protoboard` command and the VS Code extension use it. You rarely install it by hand: the [command line](https://www.npmjs.com/package/@protoboardai/cli) and the [VS Code extension](https://marketplace.visualstudio.com/items?itemName=deltarobotics.vscode-protoboard) bring it with them.
