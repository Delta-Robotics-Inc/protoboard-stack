# @protoboardai/ext-harness-cad

3D wire harness routing from your assembled design.

Part of [Protoboard](https://github.com/Delta-Robotics-Inc/protoboard-stack), which designs hardware with your AI agent. A project lists this extension in its `protoboard.config.ts`; the Protoboard templates add it where it fits. You rarely install it by hand: the [command line](https://www.npmjs.com/package/@protoboardai/cli) and the [VS Code extension](https://marketplace.visualstudio.com/items?itemName=deltarobotics.vscode-protoboard) bring it with them.
