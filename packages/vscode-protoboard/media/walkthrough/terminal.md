## The terminal, and your agent

Terminals in this window have the `protoboard` command:

```
protoboard check       every validator; exit 1 on errors
protoboard build       the resolved model the views read
protoboard doctor      what is set up, what is missing, the sign-in
protoboard stack       where the CLI and the project's packages come from
```

**Protoboard: Add the protoboard Command to PATH** adds it to terminals
outside VS Code.

**Your agent.** Ask it to read the project's `AGENTS.md`, or connect it with
**Protoboard: Connect Agents**.
