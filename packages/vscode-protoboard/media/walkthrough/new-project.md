## Create a project

**Protoboard: New Project…** asks what to start from (blank by default) and
where to put it, then opens it.

| Template | What you start with |
| --- | --- |
| `drone` | A 5-inch quadcopter: frame, motors, flight controller, wiring |
| `wearable` | A watch: main board, display, battery, enclosure |
| `iot` | A Wi-Fi and Bluetooth board on a LiPo cell, with its PCB and firmware pin header |

No account needed. Signed out, a template's library parts are placeholders:
**Fetch Parts** adds them after you sign in.

A project from somewhere else (cloned, copied): use **Initialize** when the
Protoboard views offer it.
